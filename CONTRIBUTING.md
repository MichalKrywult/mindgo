# Contributing

First of all, thank you for your interest in this project!

I'm still learning and developing this project, so contributions, suggestions, and feedback are always welcome.

There are no strict contribution rules or complicated processes, just a few simple guidelines to keep things organized.

## 🐛 Found a bug?

If something isn't working as expected, feel free to open an issue using the bug report template, including:

- A short description of the problem
- Steps to reproduce it, if possible
- What you expected to happen
- Any additional information that might help

## 💡 Have an idea or feature request?

Have an idea for a new feature or think something could be improved?

Open a feature request using the provided template and share your thoughts.

## 🔧 Want to contribute code?

Here's how you can get started:

1. Fork the repository
2. Create a new branch for your changes
3. Make your changes
4. Commit and push your changes
5. Open a Pull Request describing what you've changed

## ❓ Have questions or feedback?

If you're unsure about something, need help, or just want to discuss an idea, feel free to open a discussion or an issue.

I'll try to answer as soon as possible.

## ❤️ Not sure if your contribution is welcome?

This project is a work in progress, and there's always room for improvement.

Whether it's a small bug report, a feature suggestion, a few lines of code, or simply some feedback, every contribution is appreciated.

Thanks for being here!
